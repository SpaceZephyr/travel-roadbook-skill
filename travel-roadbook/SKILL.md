# 旅行路书规划

把用户的出行想法变成**经过核实的行程**，并产出一个手机可打开的**路书网页链接**。

## 工作流程

### 1. 问清需求（一次问完）

用提问工具一次性问齐：出发地/目的地与具体日期天数、出行方式（自驾问车型、司机数、可接受的单日里程）、人数与构成（老人小孩、是否上高原）、目的偏好与明确不想去的地方、预算与住宿档次。出境游把路线选项和当季情况（雨季、海况）一起给出。清单与问法见 `references/roadbook-spec.md` 第一节。用户已上传行程表时先完整读表，不重复询问。

### 2. 核实与质疑（核心价值，不能省）

- 国内逐段用高德工具实测里程与时长，**不要信用户表格里的里程或直线距离**；实测低估是常态（曾发现用户表低估达 112%）。
- 按 `references/planning-rules.md` 逐条校验：单日驾驶时长、过夜中点、高原海拔阶梯、节假日放假与错峰、"不想去 X 地"是过境还是绕开、环线与游玩密度；出境游看第 9 节（入境政策、季节、开口程、现金、着装与禁忌）；季节性道路看第 10 节（封路风险路段排前面、备用路线）。
- 涉及法定节假日，用网络搜索核实当年放假安排（政府网为准）。
- 发现不合理处：明确指出问题、给替代方案和对比，关键取舍让用户拍板后再定稿。

### 3. 采集信息

- 国内：坐标、里程、天气、POI 按 `references/amap-tools.md` 的顺序调用高德 MCP（会话里还没加载时可以直接走 HTTP，见该文件末尾）。
- **境外：高德查不到数据**（坑 6），里程、天气、景点、门票、入境政策改用网络搜索，写明来源和查询日期。
- 天气只有未来约 4 天预报：覆盖不到的日期用历年同期气候，在页面注明"不是预报"。
- 门票价格、预约规则、只收现金的地方用搜索核实，标注价格时效与汇率。

### 4. 生成高德行程地图

用 `maps_schema_personal_map`（orgName + lineList，节点含 name/lon/lat/poiId，按行程时间排序）拿到 `amapuri://` 链接。境外点用占位 poiId `"0"` 加核实过的经纬度（见坑 6）。该链接只写进网页按钮，不能直接交付。

### 5. 构建路书网页

- 复制 `assets/roadbook.sample.json`，按 `references/roadbook-spec.md` 第二节填写全部模块。
- 设计按 `references/design-guide.md`：简约底子，颜色只用来区分真实类别（如城市），目的地特色靠少量线描装饰和当地文字；区域色要过配色校验。换国家时在脚本 `ORNAMENTS` 里加装饰预设。
- 运行 `python3 scripts/build_roadbook.py <data.json> <输出.html>`（发布到 claude.ai 加 `--fragment`）。
- 看一次手机宽度截图：标题是否断词、路线图标签是否压线、图表标签是否重叠。

### 6. 发布与交付

- 飞书：`lark-cli apps +deploy`；或 claude.ai：Artifact 发布并声明 `capabilities: {"downloads": true}`（长图保存要用）。详见 `references/roadbook-spec.md` 第四节。
- 用户需要扫码时用 `scripts/make_qr.py` 对发布后的 https 链接生成二维码（不要编码 amapuri）。
- 交付 https 链接，回复简短：说明模块与数据查询日期、远期天气和价格出发前再核实；没在手机上测过的功能（高德按钮、长图保存）请用户自己试。

## 参考文件（按需读取）

- `references/roadbook-spec.md`：需求询问清单、路书 JSON 字段、内容口径、自检/发布/二维码/交付全流程。**每次产出必读。**
- `references/design-guide.md`：页面设计原则、目的地文化装饰、区域色校验、图表与长图分享。**构建网页前必读。**
- `references/planning-rules.md`：行程合理性质疑规则（里程阈值、高原、节假日、绕路权衡、非自驾变体、出境游、季节性道路）。规划阶段必读。
- `references/amap-tools.md`：高德 MCP 工具参数、调用顺序、lineList 结构、实测坑（含境外无数据）、HTTP 直连。调用高德工具前必读。

## 资产与脚本

- `assets/roadbook.sample.json`：出境游示例（2026 国庆广州出发，清迈 4 天 + 曼谷 3 天，泰国装饰）。
- `assets/roadbook.xinjiang.json`：国内包车示例（2026 国庆深圳出发，独库公路 + 那拉提 + 伊宁 + 赛里木湖，毡房装饰，含封路备用方案）。
- `scripts/build_roadbook.py`：JSON → 自包含路书 HTML（文化装饰预设、七天一览、经纬度路线图、气温/门票/花费图表、悬停说明、出发前清单、长图分享；`--fragment` 输出 Artifact 用的片段）。
- `scripts/make_qr.py`：发布链接 → 二维码 PNG。
