# 路书网页设计规范

`build_roadbook.py` 已经实现了下面这套设计，正常情况下只需填 JSON。
本文说明设计的原则，以及换一个目的地时要改哪几项。

## 一、底子：简约

- 颜色只用黑、灰，加上目的地的 1–3 个区域色。**颜色必须对应真实的区分**，比如两座城各一个颜色；
  上午、下午、晚上属于同一类信息，就用同一种样式，不要单独给某一栏上色。
- 少用卡片和边框。用留白和一条细线来分组，每天之间一条线就够了。
- 字体：标题和日期用宋体（Noto Serif SC），正文用黑体（Noto Sans SC），当地文字用对应的 Noto Serif 字体。
- 数字对齐用 `tabular-nums`；中文标题用 `text-wrap: balance`；h1 按词组分成几段，不要让城市名断行。

## 二、目的地特色：少量装饰 + 当地文字

特色主要靠内容来体现，比如按真实经纬度画的路线图、带日期的出发前清单；装饰只放一点点：

| 位置 | 做法 | 泰国示例 |
|---|---|---|
| 开头右侧 | 一幅线描，只描边、不填色 | 寺庙山墙：三层屋檐，檐角上翘，顶端 chofa |
| 开头下方 | 一行重复纹样 | 莲花苞 |
| 城市名旁 | 当地文字，用该城市的区域色 | เชียงใหม่ / กรุงเทพฯ |
| 每天日期下 | 当地文字写的"第几天"，用当地数字 | วันที่ ๑ … ๗ |
| 注意事项 | 一两句当地问候语 | สวัสดี（萨瓦迪）、ขอบคุณ（阔昆） |
| 页脚 | 当地文字的"一路平安" | เดินทางปลอดภัย |

已有预设：`thai`（寺庙山墙 + 莲花苞）、`kazakh`（毡房 + 羊角纹，用于新疆伊犁等哈萨克族聚居地）、`none`。
国内少数民族地区也可以用装饰预设；当地文字拿不准拼写时（如阿拉伯字母书写的哈萨克文、维吾尔文）不放文字，`local_lang` 填 `none`。

**换国家时**：

1. 在 `build_roadbook.py` 的 `ORNAMENTS` 里加一项。`hero` 是一组路径，画在 viewBox 里；`border` 是
   22×12 单元里的纹样（用 currentColor 填充）。可参考的题材：日本用鸟居或青海波，韩国用韩屋屋檐，
   越南用斗笠或莲花，印尼用巴厘岛的山门，法国用铁艺阳台栏杆。只画轮廓，别做复杂插画。
2. `LOCAL_FONTS` 里没有对应语言的话，补上 Google Fonts 的字体名。
3. 当地文字（城市名、问候语、数字）必须核对，拿不准的就别用。没有独特文字的国家就不放。

## 三、区域色怎么选

- 从当地文化里取：清迈用兰纳土布的靛蓝 `#3d56a6`，曼谷用寺庙金 `#b3862a`。
  其他参考：京都的抹茶绿或朱红、首尔的丹青蓝、巴黎的铁灰、巴厘岛的赤陶。
- 浅色、深色模式各要一套，用 dataviz 技能的 `validate_palette.js` 检查亮度区间、色弱区分度和对比度
  （浅色底 `#fbfaf6`、深色底 `#15171a`），**全部 PASS 才能用**：
  ```
  node <dataviz>/scripts/validate_palette.js "#3d56a6,#b3862a" --mode light --surface "#fbfaf6"
  node <dataviz>/scripts/validate_palette.js "#6a80d4,#b88d30" --mode dark  --surface "#15171a"
  ```
- 文字不用区域色，只有大号的日期和当地文字可以用。

## 四、可视化（都由 JSON 生成）

| 模块 | 回答的问题 | 字段 |
|---|---|---|
| 七天一览 | 哪天在哪座城、哪天坐飞机、哪天有夜市 | `overview[]` |
| 路线示意图 | 几座城的相对位置、每段飞多久 | `route` |
| 气温区间 | 各城平均最低/最高温 | `weather.rows[]` |
| 每日门票 | 哪天花钱最多 | `tickets.rows[]` |
| 花费区间 | 整趟每项大概多少 | `budget.rows[]` |

- 路线图按真实经纬度投影。东西长、南北窄的地域（如伊犁）画出来是扁的一条，标签容易挤：去掉航段上的 `label`，
  公里数写进每天的安排；城市标签用 `label_dx/label_dy` 调位置，靠左边缘的点把标签放右侧。
- 气温只画查得到可靠月平均的地点；山区、湖边查不到就写在 `fine` 里定性说明，不要为了图好看补数字。
- 图表上直接标数值；鼠标悬停或点按会显示说明（`tip`），门票图下面还能展开明细表。
- 一个图里只用一种刻度，不做双坐标轴。
- 没有数据的就不画。比如门票查不到，就写"看官网"，不要编一个数。

## 五、长图分享

「每天怎么走」标题右侧有「生成长图」按钮：它把七天一览和逐日行程画成 PNG，宽 720 CSS 像素、按 2 倍导出，
用 cdnjs 上的 html2canvas 1.4.1。

- 生成后先弹出预览，手机上长按图片可以保存。
- 普通网页（比如用飞书发布的）会显示「下载图片」按钮。
- 发布到 claude.ai Artifact 时，页面不能自己触发下载，**发布时要声明 `capabilities: {"downloads": true}`**，
  预览里会显示「保存图片」按钮，保存前用户会看到确认框。
- 长图固定用浅色；图标和装饰的 SVG 在导出时会换成固定颜色，因为 html2canvas 读不到 CSS 变量。

## 六、要避免的

- 为了显得有特色，给某一类信息单独上深色底、渐变或色块。
- 每个区块都套一张带阴影的卡片，框里再套框，每块左边加彩色竖线。
- 用 emoji 当图标；装饰画得太复杂、太大，抢了正文。
- 滚动时让内容飞进来；做出看着能点、其实点了没反应的元素。
